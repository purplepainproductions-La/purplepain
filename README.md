# Purple Pain Productions ☂️🌌

> **The Art of the Surreal** — A cosmic noir digital experience for avant-garde streetwear, music, and media.

## 🎨 Design System & Aesthetic
- **Theme:** Cosmic Noir / Deep Space Glassmorphism
- **Primary Color:** Electric Purple (`#8B2CF5` / `#D8B9FF`)
- **Secondary Color:** Vibrant Magenta (`#FF007A` / `#FFB1C3`)
- **Typography:** Space Grotesk (Headlines), Manrope (Body), JetBrains Mono (Labels/Price)

## 📄 Site Structure
- `index.html` - Homepage / Main Showcase
- `catalog.html` - Curated Collection & Filters
- `product.html` - Product Detail View
- `cart.html` - Shopping Cart / Stasis Checkout
